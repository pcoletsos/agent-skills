# References - prose-style-guide

## Em Dash Replacements Reference

| Context | Instead of Em Dash (`—`) | Recommended Alternative | Example |
|---|---|---|---|
| Parenthetical aside | `The system—while fast—failed.` | Commas or parentheses | `The system, while fast, failed.` or `The system (while fast) failed.` |
| Amplification / explanation | `We chose Kafka—it handles high throughput.` | Colon or separate sentence | `We chose Kafka: it handles high throughput.` or `We chose Kafka. It handles high throughput.` |
| Abrupt contrast | `Good architecture—not lucky guesses—wins.` | Commas | `Good architecture, not lucky guesses, wins.` |
| Itemization intro | `Three tools are available—n8n, LangChain, and Temporal.` | Colon | `Three tools are available: n8n, LangChain, and Temporal.` |
